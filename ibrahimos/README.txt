RUN IT
1. Extract ibrahimos.zip to a folder.
2. Double-click index.html to open it in Edge or Chrome.
3. Click the desktop icons or dock icons to explore.
4. Open Personalize to switch themes; open Terminal and type help.

EDIT YOUR DETAILS

Don't add private information such as a home address, phone number, passwords, or personal ID numbers to a page other people might see.

MAKE IT APPEAR WHEN YOU SIGN IN TO WINDOWS (OPTIONAL)
This opens the website after you sign in; it does not change the Windows lock screen.
1. Keep index.html in a permanent folder (for example Documents\IbrahimOS).
2. Press Win+R, type shell:startup, then press Enter.
3. In that Startup folder, right-click > New > Shortcut.
4. Browse to your browser (for Edge, usually C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe) or use Chrome's executable.
5. After the browser path in the shortcut's Target, add a space and the full path to index.html in double quotes. Example:
   "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" "C:\Users\YOURNAME\Documents\IbrahimOS\index.html"
6. Give the shortcut the name IbrahimOS. On the next sign-in it should open.

EASIER STARTUP ALTERNATIVE
In Edge or Chrome, you can set the local file as the browser's startup page, if supported by your browser settings. Startup folder shortcut above is more predictable.
